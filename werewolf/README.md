# 狼人杀 × Jev / Laya

6 人局：2 狼人 / 1 预言家 / 1 女巫 / 2 平民。每座可选 玩家 / Jev / Laya。

与其他 army-chess 项目一样的 `state+questions -> answers` 契约，但没有把
"自由发言"直接交给模型写纯文本——而是用几道结构化选择题（针对谁、立场、是否
跳身份/查验结果、理由模板）驱动模型的**社交推理判断**，再由服务端拼成中文发言。
模型负责"想法"（该不该悍跳、怀疑谁、何时归票），文字生成交给模板，这样可以复用
已验证的 choice/score/noul 契约，不依赖未经验证的自由文本接口。

## 规则

- 夜晚：狼人共同选择击杀目标（存活狼人多数投票，平票随机）；预言家查验一人，
  得知"狼人/好人"；女巫每晚最多使用一瓶药（解药救人 或 毒药杀人，二选一，
  全局各只有一瓶）
- 白天：存活玩家按座位顺序发言，然后投票放逐一人（最高票出局，平票无人出局）
- 胜负：狼人数 ≥ 好人数 时狼人获胜；狼人全部出局则好人获胜
- **夜杀身份保密，票出局身份公开**——符合真实桌面规则的信息边界，AI 和人类
  玩家看到的"已出局名单"都遵循这个规则

## 运行

```bash
pip install -r requirements.txt
python3 app.py          # http://127.0.0.1:5057
```

`LAYA_ENABLED=0` 可关闭 Laya。KNOX_API_KEY 环境变量可覆盖内置 key。
回放：`/replay`（每局独立 JSON，实时落盘于 `replays/`，含完整发言记录）。

## 已知简化（非 bug）

- 投票平票时无人出局，没有二轮加投
- 没有"遗言"环节
- 女巫一晚只能用一瓶药（不支持同晚救人+毒人）
- 发言是结构化选择题拼接成句，不是模型自由撰写的文本
