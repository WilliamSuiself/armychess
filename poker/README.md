# 德州扑克 × Jev / Laya

三人无限注德州扑克。每座可选 玩家 / Jev / Laya。

- 盲注 10/20，起手 1000，按钮轮转，最多 20 手
- 四街下注（翻牌前/翻牌/转牌/河牌），支持 弃牌/过牌/跟注/加注（最小加注、半池、满池、全下）
- all-in 多层边池正确结算；摊牌标准五选七比大小
- **AI 状态含**：公共牌、底池、赔率、各街完整动作历史、位置——供范围推理
- 对手手牌摊牌前对 AI 不可见（回放帧保留全量记录供事后查看）

## 运行

```bash
pip install -r requirements.txt
python3 app.py          # http://127.0.0.1:5054
```
