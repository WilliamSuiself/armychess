# UNO × Jev / Laya

四座位，标准 108 张牌。每座可选 玩家 / Jev / Laya。

- 标准配色数字牌 + 禁出/反转/+2 + 万能/万能+4
- 能出牌必须出（简化规则，无主动摸牌选项）
- 万能+4 仅在手中无当前颜色牌时合法（标准规则）
- 先到 300 分（累计对手剩余手牌点数）获胜
- **AI 可见的"记牌"信息**：`unaccounted_by_color`——不在你手上也不在弃牌堆的牌（摸牌堆+对手手里），按颜色统计，可用来判断"叫哪个颜色更安全/更稀缺"

## 运行

```bash
pip install -r requirements.txt
python3 app.py          # http://127.0.0.1:5056
```

`LAYA_ENABLED=0` 可关闭 Laya。KNOX_API_KEY 环境变量可覆盖内置 key。
回放：`/replay`（每局独立 JSON，实时落盘于 `replays/`）。

## 已知简化（非 bug）

- 能合法出牌时必须出，不支持"明明能出但选择摸牌"
- 没有"忘记喊 UNO 被罚牌"的抓包机制
- +2/+4 不支持连续叠加（标准玩法的常见房规，但非官方强制规则）
