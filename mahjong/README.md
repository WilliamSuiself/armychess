# 四人麻将 × Jev / Laya

四人川麻式麻将。每座可选 玩家 / Jev / Laya。

- 108 张（万/筒/条 1-9 各四张，无字牌、无吃）
- 碰 / 明杠 / 加杠 / 暗杠 / 胡（自摸+点炮），杠后补摸
- 胡牌型 = 4 面子 + 1 雀头；流局换庄，胜者连庄，共 8 局比总分
- **AI 状态含活牌计数**：每种牌在"墙+别人手里"还剩几张（4 - 自己手牌 - 全场弃牌/副露）
- 前端有实时活牌表；兜底策略用向听数+孤张/安全度评估
- 对手暗牌对 AI 不可见；回放帧保留全量记录

## 运行

```bash
pip install -r requirements.txt
python3 app.py          # http://127.0.0.1:5055
```
